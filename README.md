# adhikarx-ai
AdhikarX AI is a gamified election education platform designed to empower first-time voters through interactive learning, real-time AI assistance, constituency exploration, and simulation-based experiences.

## ✨ Features
- 🧠 Real-time AI Assistant (OpenAI-powered)
- 🎮 Gamified learning with XP, badges & levels
- 🗺 Explore constituency & compare candidates
- 🧪 Interactive quizzes & simulations
- 🏆 Certificate generation with download
- 🔐 User authentication & progress tracking
